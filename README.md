# Devlog — Berke Irak

Eenvoudige website voor GitHub Pages, ingedeeld per sprint.

- `index.html`: overzicht van de sprints.
- `sprint-1.html`: ideeën, bijdrage, proces en vooruitblik van sprint 1.
- `sprint-2.html`: O&P Rijk, hardware, ethische analyse, Society 5.0, seminar, feedback en reflectie.
- `styles.css`: eenvoudige opmaak, geschikt voor desktop en mobiel.
- `assets/`: afbeeldingen en enquêteresultaten.

## Aanpassen
Bewerk de HTML-pagina van de betreffende sprint. Afbeeldingen gaan in `assets/`. Een volgende sprint krijgt een eigen HTML-pagina en een link op het overzicht en in de navigatie. Er zijn geen installatie- of buildstappen nodig.

## Publicatie
GitHub Pages publiceert de hoofdmap van de `main`-branch. Website: https://irakberke.github.io/DevLog/

## Inhoud
Teksten en afbeeldingen zijn overgenomen uit de bestaande devlog. De feedback uit de zes aangeleverde formulieren is samengevat bij sprint 2. De nog ontbrekende bewijsstukken zijn daar benoemd: hardwareoverzicht, herzien verslag over paternalisme en origineel enquêteformulier met QR-code.
